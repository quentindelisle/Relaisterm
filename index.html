Réglages

Le barème fixe (établi sur 100 m) est proratisé à la distance choisie. Les courses déjà enregistrées gardent la distance à laquelle elles ont été courues.

Vitesse Zt = longueur Zt ÷ temps dans la Zt. Vitesse hors Zt = (distance totale − Zt) ÷ (temps total − temps Zt). Écart = (V Zt − V hors Zt) ÷ V hors Zt.

Barème autoréférencé : meilleure course de la classe = 5, moins bonne = note minimale (1 par défaut), linéaire entre les deux.

Notation d'une course (/20)

Critères /10

  • Transmission valable (main) : 3 pts
  • Ne se retourne pas : 3 pts
  • Écart de vitesse Zt / hors Zt :
    • plus rapide dans la Zt : 4 pts
    • vitesse proche (0 à −8 %) : 3 pts
    • vitesse correcte (−8,1 à −15 %) : 2 pts
    • vitesse faible (−15,1 à −20 %) : 1 pt
    • vitesse inférieure (au-delà de −20 %) : 0 pt

Les critères sont attribués au démarreur et au relayeur.

Performance /10 (temps total du relais)

  • Barème fixe /5 : barème relais 100 m du lycée, filles / garçons, proratisé à la distance courue (chaque élève est noté avec le barème de son genre).
  • Autoréférencé /5 : meilleure course de la classe = 5 · moins bonne = 1 · linéaire entre les deux.

Note finale /20 = somme des N meilleures courses ÷ N (N = 3, 4 ou 5, choisi dans Résultats ; course manquante = 0).
